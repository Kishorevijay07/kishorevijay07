### 🎙️ [Another Me](https://github.com/kishorevijay07/Another-Me) — AI Companion Platform
A personal AI system with a push-to-talk voice interface (in-browser STT + Kokoro neural TTS), long-term memory, and provider-agnostic LLM routing (Gemini-primary with local Ollama fallback). Built with a structured, spec-driven development workflow and a FastAPI backend.

`Python` `FastAPI` `LLM Routing` `Speech AI` `SQLite`

---

### 🤖 [AgentOS](https://github.com/kishorevijay07/AgentOS) ⭐
A runtime for building and orchestrating LLM agents — pluggable tool registry, shared memory across agents, a planner that decomposes goals into sub-tasks, and streaming multi-agent workflows over WebSockets. Model-agnostic with built-in RAG.

`Python` `LangGraph` `FastAPI` `Vector DB` `Multi-Agent`

---

### 🧩 [Multi-Tasking Agents](https://github.com/kishorevijay07/Multi-Tasking-Agents)
A multi-model AI agent built with an orchestrator, RAG pipeline, and chat services enabling dynamic, multi-model interaction and decision-making.

`FastAPI` `RAG` `LLMs` `Orchestration`

---

### 🔬 [Multimodal OCR System](https://github.com/kishorevijay07/Multimodel-OCR-System) ⭐
An advanced OCR system that dynamically combines multiple models to extract text from noisy, low-quality, and mixed-format documents, with multi-stage post-processing for structured data generation.

`Python` `OpenCV` `Tesseract` `Deep Learning`



### 🧠 Offline AI Python Programming Coach
